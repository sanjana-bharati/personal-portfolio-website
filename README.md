# Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, achievements, and contact information.

## Live Demo

Visit the website here:

https://sanjana-bharati.github.io/personal-portfolio-website/

## Features

* Responsive design for desktop and mobile devices
* Interactive navigation menu
* About Me section
* Skills, Experience, and Education tabs
* Services section
* Project showcase with hover effects
* Contact form integrated with Google Sheets
* Resume download functionality
* Social media links

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* GitHub Pages
